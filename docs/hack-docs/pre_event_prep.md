## Frequently Asked Questions

**What exactly do we have to build?**

Each team will build an AI-powered financial solution using the Alpaca SDK and Orca agent framework. Choose one of the following directions:

- A trading algorithm or robo-advisor that makes or suggests investment decisions based on market data.
- A saving algorithm that analyses income and spending patterns to optimise savings.
- A money admin tool that helps users track, categorise, and manage their finances.
- A financial advisor agent that answers financial questions and recommends actions based on user context.

At the final demo, all solutions will be presented live and connected through Orca for orchestration and visibility.

**What tech stack can we use?**

You must use Python or JavaScript (Node.js), as these are supported by the Orca SDK. You are free to use frameworks such as LangChain, CrewAI, or similar. AI coding assistants like Copilot are encouraged. A boilerplate GitHub repo with Orca and Alpaca integration will be provided so you do not waste time on setup.

**Do we need to deploy anything?**

No DevOps headaches. You will develop locally during the sprint, and Orca will handle cloud orchestration and visibility for demos. Servers used for the hackathon will be deleted afterward unless needed for showcasing.

**How are teams structured and assigned challenges?**

Expect teams of 3–4 people with mixed profiles: engineers, product, finance, and GTM. Teams will be formed on-site to balance skills across the group. Each team selects their own solution direction from the four categories above.

**Do we need prior experience with Orca or Alpaca?**

No. A boilerplate starter repo with Orca and Alpaca integration will be provided. You focus on the product logic and solution design, not setup.

**Who owns the code and IP?**

You do. All code built during the hackathon remains yours. Nothing is retained by the organizers unless you explicitly choose to continue showcasing it.

## 1. Register on Orca

Head to the registration page and create your account:

🔗 Orca Platform Hackathon Register

Once registered, log in and navigate inside Orca. You will see your team assignment — for example:

- Team 1
- Team 2

## 2. Install Dependencies

Make sure you have Node.js / npm installed on your machine, then install the Orca CLI globally:

```bash
npm install -g @orca-pt/cli
```

## 3. Configure Orca Endpoint

Point the CLI to the MADHACK Orca instance by setting the environment variable:

```bash
export ORCA_API_URL="https://hacketon-26april-api.orcapt.com"
```

⚠️ **Important:** Make sure to set this variable in every new terminal session, or add it to your shell profile (`.bashrc`, `.zshrc`, etc.).

## 4. Create Your API Key

1. Go to Orca Admin panel
2. Navigate to **Settings → API Key**
3. Click **Create auth for workspace**
4. Name it using this format: `Firstname Lastname-team-N`
   - Example: `John Due-team-1`

Save your API key — you'll need it in the next step!

## 5. Authenticate via Orca CLI

Run the login command and enter your credentials:

```bash
orca login
```

When prompted, fill in:

| Field     | Value                          |
|-----------|--------------------------------|
| Workspace | `hacketon-26april`             |
| Token     | (the API key you just created) |

## 6. Clone the Boilerplate

Clone the official MADHACK boilerplate repository and get it running:

```bash
# 1. Clone this repo
git clone https://github.com/orca-builders/hackathon-26april-boilerplate.git && cd boilerplate-alpaca
```

Then install dependencies and run the project:

```bash
# 2. Install and run the agent
cd agent
pip install -r requirements.txt
python main.py
# → runs on http://localhost:8000
```

💡 **Note:** We are not using the Orca UI from CLI. We are working directly with the ORCA MADHACK Workspace.

## 7. Create Your AI Agent

1. Go to **Admin → Agents**
2. Click **Connect Agentic System**
3. Fill in:
   - **Name:** A unique name for your agent
   - **Description:** What your agent does
   - Select your AI provider and model

## 9. Connect with Ngrok

To expose your local agent to Orca, use Orca Tunnel (or any other tunneling tool):

```bash
orca tunnel 8000
```

Once ORCA TUNNEL is running, copy your public URL and enter it in Orca:

```
URL-OF-TUNNEL/api/v1/send_message
```

Then click **Connect and Test** to verify everything is working! ✅

## 10. Happy Coding!
